## 어떻게 계산했나

시그널이 난 날 **종가**에 그 목록 상위 20종목을 같은 금액씩 사서 N거래일 뒤 종가에 판 것으로
계산합니다. 감자·액면분할·무상증자는 상장주식수 변화로 감지해 과거 주가를 소급 조정합니다.

**반영하지 않은 것**: 거래비용, 세금, 슬리피지, 상한가로 못 사는 경우.
수익률을 채우지 못한 상장폐지 종목은 집계에서 빠집니다(생존편향).
전부 실제 성과를 이 표보다 **낮추는** 방향입니다.

자세한 규칙: <https://maedong.kr/method> · 화면으로 보기: <https://maedong.kr/verify>

## 갱신

GitHub Actions 가 매 평일 공개 API 에서 받아 커밋합니다. 사람 손이 닿지 않습니다.
API 는 인증이 없어 누구나 같은 값을 받을 수 있습니다: <https://maedong.kr/api>
